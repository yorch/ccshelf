# ccshelf

Profiles and a plugin catalog for Claude Code. Unofficial: not affiliated with Anthropic.

**Status:** implemented and under adversarial review; not yet released. The launcher, catalog, Action and starter template build and pass their tests on all six targets; Phase 0 evidence items (routing eval, adopt-or-build, bundle prototype, Linux/Windows runs) are still open, see the [roadmap](docs/design/roadmap.md). Start with [docs/README.md](docs/README.md) and the [decision log](docs/DECISIONS.md). The interactive report is `docs/report.html`, generated from the Markdown.
