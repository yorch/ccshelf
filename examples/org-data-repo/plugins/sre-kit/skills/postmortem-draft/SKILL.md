# Postmortem draft

Write the sections in this order: summary, impact, timeline, root cause, contributing factors, what went well, what went poorly, action items.

Rules: blameless wording (describe systems and decisions, not people), each action item has an owner and a due date placeholder, and every claim points back to a timeline entry.
