# SEO audit

Check, in order: `<title>` length and uniqueness, meta description, one `h1` and a sensible heading outline, canonical URL, `robots` directives, structured data validity, internal links and image `alt` text.

Return a table of issue, location, impact (high, medium, low) and suggested fix. Use the Search Console MCP server only for read-only queries.
