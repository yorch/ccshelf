# Accessibility check

- Every interactive element is reachable and operable with the keyboard.
- Images have text alternatives; decorative images use an empty `alt`.
- Form controls have visible labels; errors are announced.
- Focus is visible and the tab order follows the reading order.
- Text and controls meet the WCAG 2.1 AA contrast ratios.

Report each problem with the element, the rule it breaks and a one-line fix.
