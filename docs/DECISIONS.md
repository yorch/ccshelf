# Decision log

One row per decision, newest direction last. Never delete a row: when a decision changes, mark it **Superseded** and point to the row that replaces it. Add every new decision here, with the evidence and a trigger for revisiting it. Confidence markers: {V} verified in docs, `gh` or the CLI; {R} reported by a research agent and not independently re-checked; {U} unverified or inferred. "User" means the decision was made by the project owner.

| D-29 | 2026-10-06 | **`run` uses the pinned commit and does not hit the network** when the trusted checkout is cached; `trust` and `ls --refresh` re-resolve tags. | D-30 | 2026-10-06 | **Cached git checkouts are verified down to every tree object** (replace refs disabled) before each use; when a source is unreachable the union of all pinned protect lists keeps being enforced and the newest verified cached checkout is used; plugins that own a protected MCP server are protected (all same-name candidates, with a warning). | Review Y: replace refs could swap a tree behind a pinned commit; an outage dropped protect lists of protect-only sources. | High | Next adversarial review |
| D-31 | 2026-10-06 | **Plugin sources are bound to their real marketplace source** (from `claude plugin marketplace list --json`, {V} for github, git and directory kinds) in the source id and trust key, with an optional `marketplace` check in the config; `search`, `recommend` and `doctor --policy` can use the cached org source offline; PRF002 is info for `cmd /c npx|node|uvx|bunx name@version` (the documented Windows launcher) and a warning for anything else. | Review X/Z2: the marketplace check was a dead hook; git-source users had no catalog; the starter failed `lint --strict`. | Medium | Review Z |
| D-32 | 2026-10-06 | **Marketplace identity is kind-tagged and host-neutral** (`github:owner/repo`, `git:host/path`; ssh, https and scp forms of one repo are equal; directory sources are hashed, never a machine path). **Git checkouts carry a layout version** (bump `layoutVersion` when the watched file set changes). **Catalog reads (`search`, `recommend`) use only a commit the user accepted** (the lockfile commit, or the exact SHA when the ref is one).
